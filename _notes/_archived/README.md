# Archived rounds

Earlier rounds of drafting, modelling and red-teaming on the hyperscaling-Coase essays, moved here from the livingthing blog on 2026-11-20.
Dan's judgement at the time of the move was that most of this material is mined out, so it is kept for reference and no line of work lives here.
New work goes in its own `_notes/<slug>/` folder, as the repository `README.md` describes.

## Old paths

Every file keeps the name it had in livingthing, where it sat at `_plans/<same name>`.
A reference elsewhere to `_plans/hyperscaling_coase_<x>` therefore means `_notes/_archived/hyperscaling_coase_<x>` here.
The files' history is in the livingthing repository up to commit `20a1134b04`.

The two `.qmd` files are drafts that were never promoted to posts.
They keep the extension for the sake of the old references; Quarto skips this folder.

## Scratch

`_tmp/` holds the working scratch the notes cite as run records: agent scripts, logs, raw workflow outputs and collations.
It sat at `_tmp/<same name>` in livingthing, outside version control, so a reference to `_tmp/hyperscaling_coase_<x>` or `_tmp/coase_<x>` means `_notes/_archived/_tmp/<same name>` here.
The downloaded PDFs of source papers were taken out before the move, to go into Zotero; a path in these notes that ends in `.pdf` will not resolve.
