# notes_on_agency

Quarto website (blog) on mechanized causal graphs, decision theory, and agency. Settings in `_quarto.yml`; output `_site/`.

To add a post, create `<slug>.qmd` at the repo root with `title`, `date`, `categories` and `author` front-matter. The home page (`index.qmd`) picks it up automatically.

## TikZ diagrams

The site uses the Lua filter `_extensions/danmackinlay/tikz/` ([quarto_tikz](https://github.com/danmackinlay/quarto_tikz)). See `decision-theories.qmd` for an example:

```qmd
::: {#fig-label .figure fig-align="center"}
```{.tikz}
%%| filename: label

\usetikzlibrary{bayesnet,positioning,fit}
\input{cid_styles}
\begin{tikzpicture}[scale=2, transform shape]
...
\end{tikzpicture}
```
:::
```

- Put the label, caption and alignment on the outer `:::` div.
- Set the filename with `%%| filename:`. Don't use the deprecated `{.tikz filename=...}` fence form.
- `cid_styles.tex` holds the shared node styles. It must sit in the same directory as the posts that use it, which is currently the repo root.

### Committed cache

The rendered SVGs in `.tikz-cache/` are committed, so `quarto render` works without LaTeX.

- Each cache key hashes the block source and the filter options. Editing a block or `cid_styles.tex` therefore needs LaTeX: re-render, then commit the new SVGs. Orphaned SVGs are not cleaned up automatically, so delete them by hand.
- `tex-engine` and `svg-engine` are pinned in `_quarto.yml`. Changing or un-pinning either one invalidates every cache entry.
- A cache miss without TeX does not stop the render. The figure is dropped and the log shows `pdflatex not found`.
- Keep the hash in the filename (`<label>.<hash>.svg`). It is what turns a stale entry into a visible miss.

Settled decisions:

- **pdftocairo over dvisvgm.** dvisvgm's smaller output and real text don't help, because the figures are embedded as `<img>`. Revisit this if they become inline `<svg>`.
- **No TikZJax.** It doesn't bundle `bayesnet` and can't `\input{cid_styles}`.

## Other

- `execute: freeze: true` is set. To regenerate outputs, delete `_freeze/` or run `quarto render --no-cache`.
- `references.bib` is generated by Zotero, so never edit it. Add references with the `dan-lit-search` skill and cite them as `[@Key]`.
- Use `quarto preview` while writing and `quarto render` to build the site.
