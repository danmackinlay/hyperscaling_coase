# notes_on_agency

Quarto **book** on mechanized causal graphs, decision theory, and agency (MacDermott et al. framing). Outputs: HTML (chaptered, with Hypothesis annotations), DOCX. Output dir: `_book/`. (JATS is not supported by book projects.)

Chapters and project-wide settings (`bibliography`, `filters`, formats) live in `_quarto.yml`. Only files in `project: render:` are rendered — stray `.md` (e.g. this file) are ignored. To add a chapter: create `foo.qmd`, then add it to both `project.render` and `book.chapters`.

## Diagram rendering — TikZ

Custom TikZ filter: `_extensions/danmackinlay/tikz/` (v1.3.0, Lua-based).

**Usage pattern** (match `index.qmd` exactly):

```qmd
::: {#fig-label .figure fig-align="center"}
```{.tikz filename='label'}
\usetikzlibrary{bayesnet,positioning,fit}
\begin{tikzpicture}[scale=2, transform shape]
% ... TikZ code ...
\end{tikzpicture}
```
:::
```

- Code fence is `{.tikz}` — this is a Lua filter, not a knitr engine. No `r`/`python`.
- Figure label, caption, and alignment go on the outer `:::` div, not inside the block.
- `filename='...'` attribute controls the cache key.

**bayesnet library** — key commands for causal graphs:
- `\node[obs] (X) {$X$}` — observed variable (shaded circle)
- `\node[latent] (W) {$W$}` — latent variable (open circle); redefine style if needed: `\tikzstyle{latent}=[circle, draw, thick, minimum size=1cm]`
- `\edge {A} {B}` — directed edge A → B
- `\plate {name} {(node1)(node2)} {label}` — plate notation

**Rendering pipeline:** pdflatex → SVG (via inkscape/dvisvgm/pdftocairo). Requires local LaTeX.

**TikZJax** (browser WebAssembly, no LaTeX needed): add `tikzjax: true` as a block attribute.

**Cache:** `~/.cache/tikz-diagram-filter/` — delete to force re-render.

## Execution / freeze

`execute: freeze: true` in `_quarto.yml` — all cell outputs are cached. To regenerate: delete `_freeze/` directory or run `quarto render --no-cache`.

## Bibliography

`references.bib` is autogenerated by Zotero — **never edit directly**. To add a reference, use the `dan-lit-search` skill (uploads to Zotero first, which syncs the bib). Cite as `[@CitationKey]`.

## Build

```sh
quarto preview          # live book preview (per-chapter)
quarto render           # all formats (HTML book, DOCX, JATS) → _book/
quarto render --to html # single format
```
